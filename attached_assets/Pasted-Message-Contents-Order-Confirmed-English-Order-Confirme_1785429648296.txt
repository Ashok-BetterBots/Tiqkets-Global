Implementation Notes

Each variable appears exactly once per template (Meta rejects duplicates), so pass each value once.
Variable order differs between English and Tamil for the same trigger (see table) — map parameters per template, not per trigger.
Order Confirmed no longer includes the order ID in the opening sentence; it appears only in the "Order ID" line (previously "Token Number").
Keep the existing trigger logic unchanged — only the send mechanism changes from session message to template message.
