Part 1 — Visual & UX Redesign
1. Add a progress stepper at the top
Replace the flat single-page scroll with a 4-step visual indicator: Location → Date & Time → Your Details → Confirm. Keep all steps on one scrollable page for now (don’t build multi-page routing), but the stepper should visually anchor progress and auto-highlight the current section as the user scrolls.
2. Fix the time slot picker — biggest problem area
Currently: 26 near-identical two-column cards, each repeating “• 50 left,” with no clear selected state. Replace with:
	•	Group slots into collapsible bands: Morning / Afternoon / Evening
	•	Render as compact chips (not full cards) — pill-shaped, ~3 per row
	•	Selected chip: filled raspberry background, white text, subtle check icon
	•	Only show the “X left” badge when remaining count drops below ~15 (urgency signal, not noise) — otherwise leave it clean
	•	Ensure the whole picker doesn’t dominate the page height
3. Fix the horizontal date scroller
The third date pill is currently cut off at the screen edge with no scroll affordance. Add a visible scroll hint (partial next-card peek + subtle fade/gradient edge, or left/right chevrons) so users know more dates exist.
4. Consistent card system
Every section (location, date, slot, details, summary) should share the same card style: same border-radius, padding scale, and elevation. Right now sections feel inconsistently spaced.
5. Form fields
	•	Use floating/animated labels instead of static gray placeholders
	•	Inline, real-time validation (WhatsApp number format, email format) with small helper text under each field, not just red asterisks
	•	Combine “Full Name” + “WhatsApp Number” into a visually grouped “Your Details” card
6. Fix the checkbox row
“I am visiting with kids or senior citizens or pregnant women *” reads oddly as a mandatory checkbox. Reframe as a toggle/switch with a short label, and only show the asterisk logic if it’s genuinely required — otherwise remove it, since a “no” answer shouldn’t be blocked as invalid.
7. Sticky bottom bar on mobile
Make the Register button + live total (Order Summary total) sticky at the bottom of the viewport once the user scrolls past the order summary, so the CTA and price are always visible.
8. Order summary
Keep the raspberry accent line, but tighten spacing and make “Advance ₹1,000 — fully redeemable at billing” visually part of the summary card (currently floats as loose text below it).
9. General polish
	•	One consistent accent color (raspberry) used sparingly for CTAs/selected states only — avoid competing colors
	•	Minimum 44px tap targets throughout
	•	FAQ and Terms accordions: keep current pattern, just align padding/typography with the rest of the form
