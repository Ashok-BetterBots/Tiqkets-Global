When creating a Razorpay Route linked account via the v2 API, the account status initially surfaces as a hyphen (-) or "not activated". [1] 
To fully initialize and activate a linked account in test mode through the API, you must complete Razorpay's mandatory multi-step onboarding sequence. The account will remain locked or inactive until the dependent profiles are requested. [1, 2] 
## Step-by-Step API Activation Flow
To activate the account, execute these four specific API calls in order: [1, 2] 
## 1. Create the Linked Account (Already Completed)
Ensure you pass the correct email and business_type. You will receive an acc_XXXXX ID. [1, 3] 

POST https://api.razorpay.com/v2/accounts

## 2. Create a Stakeholder
An account must have an associated owner or stakeholder assigned to it before it can activate. [1, 2] 

POST https://api.razorpay.com/v2/accounts/{account_id}/stakeholders

Required JSON Body Fields:

{
  "name": "Test User",
  "email": "testuser@example.com",
  "percentage_ownership": 100,
  "relationship": {
    "executive": true,
    "director": true
  }
}

## 3. Request a Product Configuration
You must explicitly declare what features the linked account will use (e.g., standard payment routing). [1, 2] 

POST https://api.razorpay.com/v2/accounts/{account_id}/products

Required JSON Body Fields:

{
  "product_name": "route",
  "tnc_accepted": true
}

## 4. Update Product Configuration (Add Test Bank Routing)
Provide dummy settlement bank details so the simulation layer has a valid destination node. [1, 2] 

PATCH https://api.razorpay.com/v2/accounts/{account_id}/products/{product_id}

Required JSON Body Fields:

{
  "settlements": {
    "account_number": "1234567890",
    "ifsc_code": "RAZR0000001",
    "beneficiary_name": "Test Vendor"
  }
}

## How to Check the Final Activation Status
Once you execute the configuration steps above, call the status check endpoint to confirm the environment state transitioned to active: [1] 

GET https://api.razorpay.com/v2/accounts/{account_id}/products/{product_id}
